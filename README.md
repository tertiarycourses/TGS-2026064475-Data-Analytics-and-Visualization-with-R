## Package

- Visual, concept-led trainer slides (`v12.0`) with editable native PowerPoint charts.
- Learner slide PDF, detailed Learner Guide (DOCX/PDF/Markdown), and Lesson Plan (DOCX/PDF).
- Ten self-contained R labs. Every lab includes a runnable `.R` script, its own `.xlsx` intake/control/evidence workbook, source data, and README/PDF.
- Aligned WA/PP assessments are maintained privately in Google Drive and are intentionally excluded from GitHub.

## Learning units

1. Data Preparation and Transformation
2. Data Summary
3. Quantitative Data Analysis
4. Qualitative Data Analysis
5. Data Visualization

## Lab structure

| Lab | Outcome |
|---|---|
| 1 | Prepare and transform dengue surveillance data |
| 2 | Join, reshape and aggregate vaccination data |
| 3 | Summarise centre, spread and distribution |
| 4 | Build grouped tables and basic plots |
| 5 | Analyse correlation and regression |
| 6 | Test differences and compare groups with t-tests/ANOVA |
| 7 | Prepare text and analyse term frequency |
| 8 | Create and critique a reproducible word cloud |
| 9 | Build layered quantitative visuals |
| 10 | Review and communicate findings in a capstone briefing |

Use the detailed procedures in [LEARNER-GUIDE.md](LEARNER-GUIDE.md). The slides intentionally do not contain click-by-click lab instructions.

## Run the labs

Open a numbered folder under `labs/`, keep its `data/` subfolder intact, and run the `.R` script from that lab folder. Generated evidence is written to `outputs/`; complete the Excel workbook's Control, Evidence and Run Log sheets.
