# Lab 4: Build Grouped Tables and Basic Plots

This self-contained folder contains the runnable R script `lab-04-grouped-summary.R`, the Excel intake/control/evidence workbook `lab-04-grouped-summary.xlsx`, and the required source data under `data/`.

Use the detailed procedure in the Learner Guide. Run the script from this folder, inspect the files created under `outputs/`, complete the workbook evidence, and retain the console output.

Acceptance criteria:

- Counts reconcile to the dataset, proportions sum to 100% within rounding, every grouped statistic includes n, and the written comparison matches both tables and plots.
- The R script parses and runs without an unhandled error.
- The workbook opens without a repair prompt and contains no Excel formula errors.
- Findings identify the evidence, magnitude, uncertainty and limitation.
