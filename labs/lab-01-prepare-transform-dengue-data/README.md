# Lab 1: Prepare and Transform Dengue Surveillance Data

This self-contained folder contains the runnable R script `lab-01-data-preparation.R`, the Excel intake/control/evidence workbook `lab-01-data-preparation.xlsx`, and the required source data under `data/`.

Use the detailed procedure in the Learner Guide. Run the script from this folder, inspect the files created under `outputs/`, complete the workbook evidence, and retain the console output.

Acceptance criteria:

- The script runs without error, output rows reconcile to input less documented exclusions, dates are valid, and the clean CSV and plot are created.
- The R script parses and runs without an unhandled error.
- The workbook opens without a repair prompt and contains no Excel formula errors.
- Findings identify the evidence, magnitude, uncertainty and limitation.
