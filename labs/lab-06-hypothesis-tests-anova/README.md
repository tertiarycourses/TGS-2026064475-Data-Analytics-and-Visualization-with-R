# Lab 6: Test Differences and Compare Groups

This self-contained folder contains the runnable R script `lab-06-hypothesis-anova.R`, the Excel intake/control/evidence workbook `lab-06-hypothesis-anova.xlsx`, and the required source data under `data/`.

Use the detailed procedure in the Learner Guide. Run the script from this folder, inspect the files created under `outputs/`, complete the workbook evidence, and retain the console output.

Acceptance criteria:

- Test choices match the designs, hypotheses were pre-specified, effect estimates accompany p-values, and conclusions state assumptions and practical limitations.
- The R script parses and runs without an unhandled error.
- The workbook opens without a repair prompt and contains no Excel formula errors.
- Findings identify the evidence, magnitude, uncertainty and limitation.
