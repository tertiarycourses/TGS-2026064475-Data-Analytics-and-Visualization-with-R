# Lab 8: Create and Critique a Word Cloud

This self-contained folder contains the runnable R script `lab-08-word-cloud.R`, the Excel intake/control/evidence workbook `lab-08-word-cloud.xlsx`, and the required source data under `data/`.

Use the detailed procedure in the Learner Guide. Run the script from this folder, inspect the files created under `outputs/`, complete the workbook evidence, and retain the console output.

Acceptance criteria:

- The visual is reproducible, ranked counts are available, preprocessing sensitivity is documented, and every claim is supported by counts plus traceable excerpts.
- The R script parses and runs without an unhandled error.
- The workbook opens without a repair prompt and contains no Excel formula errors.
- Findings identify the evidence, magnitude, uncertainty and limitation.
