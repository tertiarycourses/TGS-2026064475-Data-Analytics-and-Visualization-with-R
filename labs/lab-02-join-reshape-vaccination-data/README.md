# Lab 2: Join, Reshape and Aggregate Vaccination Data

This self-contained folder contains the runnable R script `lab-02-join-reshape.R`, the Excel intake/control/evidence workbook `lab-02-join-reshape.xlsx`, and the required source data under `data/`.

Use the detailed procedure in the Learner Guide. Run the script from this folder, inspect the files created under `outputs/`, complete the workbook evidence, and retain the console output.

Acceptance criteria:

- The left join preserves all source rows, unmatched keys are zero or documented, and total doses reconcile across input, long and wide summaries.
- The R script parses and runs without an unhandled error.
- The workbook opens without a repair prompt and contains no Excel formula errors.
- Findings identify the evidence, magnitude, uncertainty and limitation.
