# Lab 9: Build Layered Quantitative Visuals

This self-contained folder contains the runnable R script `lab-09-ggplot-visuals.R`, the Excel intake/control/evidence workbook `lab-09-ggplot-visuals.xlsx`, and the required source data under `data/`.

Use the detailed procedure in the Learner Guide. Run the script from this folder, inspect the files created under `outputs/`, complete the workbook evidence, and retain the console output.

Acceptance criteria:

- All three plots answer their stated questions, remain legible without colour alone, use truthful scales and carry interpretations supported by the displayed data.
- The R script parses and runs without an unhandled error.
- The workbook opens without a repair prompt and contains no Excel formula errors.
- Findings identify the evidence, magnitude, uncertainty and limitation.
