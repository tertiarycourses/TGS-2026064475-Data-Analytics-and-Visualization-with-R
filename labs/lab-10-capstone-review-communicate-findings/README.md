# Lab 10: Capstone: Review and Communicate Findings

This self-contained folder contains the runnable R script `lab-10-capstone.R`, the Excel intake/control/evidence workbook `lab-10-capstone.xlsx`, and the required source data under `data/`.

Use the detailed procedure in the Learner Guide. Run the script from this folder, inspect the files created under `outputs/`, complete the workbook evidence, and retain the console output.

Acceptance criteria:

- The bundle reruns from source data, all controls pass or are explained, visuals agree with statistical outputs, and the recommendation distinguishes evidence from judgement.
- The R script parses and runs without an unhandled error.
- The workbook opens without a repair prompt and contains no Excel formula errors.
- Findings identify the evidence, magnitude, uncertainty and limitation.
