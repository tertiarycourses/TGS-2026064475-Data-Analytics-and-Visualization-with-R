# Lab 7: Prepare Text and Analyse Term Frequency

This self-contained folder contains the runnable R script `lab-07-text-analysis.R`, the Excel intake/control/evidence workbook `lab-07-text-analysis.xlsx`, and the required source data under `data/`.

Use the detailed procedure in the Learner Guide. Run the script from this folder, inspect the files created under `outputs/`, complete the workbook evidence, and retain the console output.

Acceptance criteria:

- Every token remains traceable to a source record, exclusions are documented, frequency totals reconcile, and the interpretation uses context rather than frequency alone.
- The R script parses and runs without an unhandled error.
- The workbook opens without a repair prompt and contains no Excel formula errors.
- Findings identify the evidence, magnitude, uncertainty and limitation.
